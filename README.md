# RADIO 001 — classic skin

Independent radio website and Chrome extension, with shared blue/metallic design and synchronized playback.

Website: https://mayabachrach.github.io/radio/

The oval design is inspired by the supplied MacPlus image. The round control sprites were extracted from the user-supplied Winamp5_Classified_v5.5.wsz. These are two different skins. Original third-party skin asset rights should be confirmed before redistributing commercially or submitting the extension to the Chrome Web Store.

This is a browser-synchronized demo, not a server-side live broadcast. Listeners must press Play; the shared clock determines playback offset. The original synthesized demo track is generated by music-synth.js on website and extension. Transport skip buttons are disabled because this is a synchronized radio station.

Use studio.html to download a revised station.json, then commit it to the repository. Audio files require appropriate online-broadcast rights.

To install extension: open chrome://extensions, enable Developer mode, choose Load unpacked and select this repo's extension/ directory. Offscreen audio keeps playing after popup closes, subject to Chrome lifecycle.

If site is not live: GitHub repo Settings → Pages → Deploy from a branch → main /(root).
