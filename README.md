# RADIO 001

Independent synchronized internet radio prototype.

This project is separate from the BGU Radio repositories.

[Live site (after Pages is enabled)](https://mayabachrach.github.io/radio/)

The player requires a click to start audio. This demo is a synchronized browser-based loop, not a server-side 24/7 broadcast.

For publishing, enable GitHub Pages in repository Settings → Pages → Deploy from a branch → main → /(root).
